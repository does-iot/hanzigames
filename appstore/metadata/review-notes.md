# 给审核员的备注（App Store Connect → App 审核信息 → 备注）

可直接复制下面英文到 "Notes" 字段（审核员看英文）。

This is a simple offline educational game for children learning Chinese characters.

How to test:
1. Launch the app. A start screen appears with a "开始游戏 / Start" button.
2. Click "开始游戏". A grid of identical Chinese characters appears with one different "odd" character hidden among them.
3. Click the different character before the timer runs out.
4. A pinyin quiz pops up. Pick the correct pinyin (also timed) to advance to the next level.
5. Chaining correct answers triggers a "combo" reward animation.

Notes for review:
- The app is 100% offline. It does NOT use the network, has no backend, no accounts, and no in-app browser.
- It collects NO user data and requests NO privacy permissions (no location, contacts, camera, mic, etc.).
- No ads, no third-party SDKs, no analytics.
- All content (Chinese characters) is sourced from standard Chinese primary-school textbooks (grades 1–3).
- Background music and sound effects are synthesized locally via Web Audio; no audio files are downloaded.
- This is a paid app (one-time purchase). There are no in-app purchases.

No demo account is required (no login).
