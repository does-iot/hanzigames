# 关键词 Keywords

App Store Connect 的关键词字段**每种语言上限 100 个字符**，用英文逗号分隔、**词间不要加空格**（空格会浪费字符）。名称和副标题里已出现的词不必重复。

## 简体中文（zh-Hans）关键词（复制下面这行）
```
汉字,找不同,拼音,识字,小学,看图,儿童,益智,找茬,专注力,人教版,形近字,二会字,启蒙
```
字符数：约 56（含逗号），在 100 以内 ✅

## English 关键词（复制下面这行）
```
hanzi,chinese,kids,spot,difference,pinyin,learn,character,puzzle,education,reading,focus
```
字符数：约 87，在 100 以内 ✅

## 小贴士
- 关键词只影响搜索，不展示给用户，**不要堆砌**与 App 无关的词（会被拒）。
- 不要使用竞品名、"免费""最好"之类的营销词或商标词。
- 单复数只需写一个（Apple 会自动匹配）。
